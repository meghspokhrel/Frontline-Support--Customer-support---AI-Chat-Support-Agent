Common questions

Understand the agent before deploying it.

Is this a real Chat automation already?

This GitHub Pages version is a realistic Demo Mode and architecture-ready frontend. Live Chat messaging requires an authorized Chat integration and secure backend processing.

Can it answer any customer question?

No. A production agent should answer from approved knowledge and business rules, clearly identify unknowns, and escalate when information or authorization is insufficient.

Can it generate leads?

Yes, as a support-to-growth capability. It can detect legitimate buying signals, ask permitted qualification questions and prepare structured handoffs to a sales or CRM workflow.

Can it work with other OrionPulse agents?

Yes. Its architecture supports structured handoffs containing business context, evidence, objective, priority, action, status, confidence and next-agent information.

What happens when the agent is unsure?

It should not guess. The system can return “Unknown — requires verification,” request clarification, consult authorized knowledge or route the conversation to a human.
